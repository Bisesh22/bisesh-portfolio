# Bisesh Ghimire — Portfolio

A responsive, modern developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. No build process or server is required.

## Deploy to GitHub Pages
1. Create a GitHub repository, for example `bisesh-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Before publishing
- Replace `your.email@example.com` with your email.
- Replace the GitHub and LinkedIn links.
- Replace each project `href="#"` with its GitHub/live-demo URL.
- Add a professional photo to `assets/profile.jpg` if you want a photo in the hero.
- Update education details with your exact college/university information if desired.

## Customization
Everything is contained in three files:
- `index.html` — content
- `style.css` — design and responsive layout
- `script.js` — navigation, theme toggle, animations and project modal
